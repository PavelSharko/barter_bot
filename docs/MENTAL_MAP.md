# 🗺 MENTAL MAP (Карта Проекта Barter Bot)

> **Для AI-агента:** Этот документ нужно всегда поддерживать в актуальном состоянии. При завершении фичи (например, по команде `finish`) или мажорном рефакторинге — обновляй этот файл, чтобы передать контекст себе в будущие сессии.

## 🏗 Архитектура и Стек
- **Язык**: Python > 3.10
- **Бот-фреймворк**: `aiogram` (асинхронная работа, Telegram API).
- **Хранилище данных**: Локальные JSON файлы в директории `DB_storge/` (`all_users.json`, `UserProfile.json`, `deals.json`, `temp_profiles.json` и др.).
- **Потокобезопасность**: База данных защищена через `FileLock` (библиотека `filelock`), чтобы избежать перезаписи при одновременных запросах.
- **Машины состояний (FSM)**: Широкое использование `FSMContext` (aiogram) для многошаговых процессов (регистрация, редактирование услуг). Все таймауты ожиданий ввода завязаны на конфиг (`config.TIME_TO_INPUT_MSG_FSM`).

## 🗂 Структура  Проекта
- **`initApp/`** — Конфигурация, загрузка переменных окружения (`config_loader.py`), запуск бота (`app_factory.py`) и фоновые/запланированные задачи (`background.py`).
- **`DB_storge/`** — JSON-накопитель, выступающий в роли NoSQL базы данных.
- **`entity/`** — Ключевой модуль архитектуры! Хранение констант и Enum (`Enums_entity.py`, `UserFields`, `UserProfileFields`, `UserMetrics`). **Любая работа с JSON-данными должна осуществляться только через эти Enum для избежания хардкода!**
- **`services/`**
  - **`keyboards/`** — Клавиатуры кнопок бота (разбитые по сценариям, например регистрации, редактирования услуг).
  - **`users_utils/`** — Модули для работы с БД (`user_profile_manager`, `temp_profile_manager`, `deals_manager`, `all_users_manager` и т.д.).
  - **`comands/`** — Логика команд бота, разделенная по группам пользователей (админы, обычные юзеры, разработчики).
  - **`send_msg_utils/`** — Логика безопасной рассылки сообщений пользователям (контроль лимитов Telegram API).
  - **`msgs_utils/`** — Обработка текста, удаление старых сообщений, генерация прогресс-баров.
- **`handlers/`** — Точки входа aiogram (роутеры сообщений, коллбеков, обработка FSM).

## 🚀 Текущий Фокус и Последние Изменения
- **Мульти-услуги**: Осуществлен переход от 1-й услуги к списку (до 15 штук).
- **Модерация (Песочница)**: Внедрен механизм черновиков для редактирования профиля. Изменения сохраняются в `temp_profiles.json` и лочатся под `UserFlags.now_is_try_changing_profile`, пока не получат одобрение от Модератора. Если модератор отклоняет изменения, прогресс (всё отредактированное) сохраняется в `temp_profiles.json`, чтобы юзер продолжил работу, а не начинал с нуля.
- **Стандартизация Конфига**: FSM ожидания приведены к единому знаменателю через параметр функции `timeout=config.TIME_TO_INPUT_MSG_FSM`.
- **Багфикс импортов**: Проведен аудит `config` - во все хендлеры и менеджеры файлов корректно прописан импорт `from initApp.config_loader import config` для избегания ошибок рантайма.
