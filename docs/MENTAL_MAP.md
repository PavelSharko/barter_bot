# 🗺 MENTAL MAP (Карта Проекта Barter Bot)

> **Для AI-агента:** Этот документ нужно всегда поддерживать в актуальном состоянии. При завершении фичи (например, по команде `finish`) или мажорном рефакторинге — обновляй этот файл, чтобы передать контекст себе в будущие сессии.

## 🏗 Архитектура и Стек
- **Язык**: Python > 3.10
- **Бот-фреймворк**: `aiogram` (асинхронная работа, Telegram API).
- **Хранилище данных**: Локальные JSON файлы в директории `DB_storge/` (`all_users.json`, `UserProfile.json`, `deals.json`, `temp_profiles.json` и др.).
- **Потокобезопасность**: База данных защищена через `FileLock` (библиотека `filelock`), чтобы избежать перезаписи при одновременных запросах.
- **Машины состояний (FSM)**: Широкое использование `FSMContext` (aiogram) для многошаговых процессов (регистрация, редактирование услуг). Все таймауты ожиданий ввода завязаны на конфиг (`config.TIME_TO_INPUT_MSG_FSM`).

## 🗂 Структура  Проекта
- **`initApp/`** — Конфигурация, загрузка переменных окружения (`config_loader.py`), запуск бота (`app_factory.py`) и фоновые/запланированные задачи (`background.py`).
  - **`run_registration_reminders`**: Пинает ленивых юнгов (отправляет напоминания тем, кто застрял на этапе регистрации `PendingRegistration`).
  - **`run_auto_cancel_deals`**: Безжалостный абордаж зависших сделок (если услуга не подтверждена за X дней, сделка отменяется, а монеты возвращаются). Баг двойного возврата монет устранен.
  - **`run_global_audit_scheduler`**: 🧮 Главный корабельный бухгалтер. Раз в сутки пересчитывает все сундуки, доходы, расходы и переводы модератора, чтобы сошлась каждая монета. Генерирует огромный Markdown-отчет и отправляет его Капитану.
- **`DB_storge/`** — JSON-накопитель, выступающий в роли NoSQL базы данных.
- **`entity/`** — Ключевой модуль архитектуры! Хранение констант и Enum (`Enums_entity.py`, `UserFields`, `UserProfileFields`, `UserMetrics`). **Любая работа с JSON-данными должна осуществляться только через эти Enum для избежания хардкода!**
- **`services/`**
  - **`keyboards/`** — Клавиатуры кнопок бота (разбитые по сценариям, например регистрации, редактирования услуг).
  - **`users_utils/`** — Модули для работы с БД (`user_profile_manager`, `temp_profile_manager`, `deals_manager`, `all_users_manager` и т.д.).
    - **`all_users_manager.py`**: Заведует реестром всех пиратов (`all_users.json`).
    - **`deals_manager.py`**: Отвечает за сделки (`deals.json`).
    - **`queue_deals_manager.py`**: Управляет очередью на услуги.
    - **`transactions_history_manager.py`**: 📜 Журнал ручных переводов. Логирует все монеты, которые Модератор раздает или переводит вручную (`history_transactions.json`).
  - **`comands/`** — Логика команд бота, разделенная по группам пользователей (админы, обычные юзеры, разработчики).
  - **`send_msg_utils/`** — Логика безопасной рассылки сообщений пользователям (контроль лимитов Telegram API).
  - **`msgs_utils/`** — Обработка текста, удаление старых сообщений, генерация прогресс-баров.
- **`handlers/`** — Точки входа aiogram (роутеры сообщений, коллбеков, обработка FSM).

## 💰 Экономика и Движение Монет (Карта Потоков)
Система работает как закрытая экономика (сумма всех `balance` + `block_balance` должна быть равна сумме всех выданных `category` + начисленных через `/send_coins`).
1. **Создание сделки (Клиент)**: `free_balance` проверяется на >= `price * 1.1`. `block_balance` увеличивается на `price * 1.1`. Свойство `balance` не меняется!
2. **Отмена сделки до выполнения (Клиентом, Исполнителем или Планировщиком)**: `block_balance` уменьшается на `price * 1.1`. Свойство `balance` не меняется!
3. **Успешное завершение сделки (Клиент нажимает Услуга Оказана)**:
    - **Клиент**: `block_balance` и `balance` уменьшаются на `price * 1.1`.
    - **Исполнитель**: `balance` увеличивается на `price`.
    - **Модератор**: `balance` увеличивается на `price * 0.1` (10% комиссия).
4. **Откат завершенной сделки модератором (`/rollback`)**:
    - **Клиент**: `balance` увеличивается на `price * 1.1`.
    - **Исполнитель**: `balance` уменьшается на `price`.
    - **Модератор**: `balance` уменьшается на `price * 0.1`.
