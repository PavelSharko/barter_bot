# Общий контекст проекта Barter Bot

## 📝 Описание
Telegram-бот для бартерного обмена (услуги/товары). 
Проект реализует разделение ролей (Пользователь, Модератор, Разработчик) и имеет структуру для горизонтального масштабирования функционала.

## 📂 Структура проекта

### 🚀 Точка входа
- **`barter_bot.py`**: Инициализация бота, диспетчера, запуск поллинга и фоновых задач.

### 🎮 Обработчики (Handlers)
В папке `handlers/` находится логика маршрутизации:
- **`message_handlers.py`**: Главный фасад. 
  - `handle_callback`: Маршрутизирует нажатия кнопок в зависимости от роли (Dev, Mod, User) или группы кнопок (Main Menu, Edit Profile).
  - `universal_handler`: Обрабатывает текстовые сообщения и команды (кроме ввода данных).
  - `universal_input_handler`: Обрабатывает ввод текста, когда пользователь находится в состоянии `FSM.waiting_input`.
- **`sub_handlers/`**: Специфическая логика.
  - `main_menu_handler.py`: Обработка кнопок главного меню клиента.
  - `edit_profile_handler.py`: (Заглушка) Обработка редактирования профиля.
  - `admin_group_handler.py`, `developer_chat_handler.py`: Логика для админов и разработчиков.

### ⚙️ Сервисы (Services)
В папке `services/` находится бизнес-логика:
- **`keyboards/`**: Клавиатуры и кнопки.
  - **`bot_all_buttons.py`**: **Центральный файл с Enum**. Здесь определены ВСЕ тексты кнопок и команд.
  - `creator_inline_keyboards.py`, `sustem_inline_keyboard.py`: Генераторы клавиатур.
- **`comands/`**: Реализация команд.
  - `users_commands/for_contacted/`: Логика регистрации и анкет (Contacted flow).
  - `admin_commands/`: Действия модератора (бан, монеты, отклонение анкет).
- **`state_bot/`**: Глобальное состояние (`FSM`, списки сообщений для удаления).
- **`users_utils/`**: Управление пользователями, проверка блокировок.

### 💾 Данные и Конфигурация
- **`config.yaml`**: Настройки токенов, ID чатов, путей к файлам.
- **`DB_storge/`**: JSON файлы с данными пользователей (`all_users.json`, `UserProfile.json`).

## 👥 Роли и Доступы
1.  **Разработчик (`DEVELOPER_CHAT_ID`)**: Полный доступ, остановка бота.
2.  **Модератор (`MODERATOR_CONTACT_ID`)**: Управление заявками, бан, начисление монет.
3.  **Пользователь**: Стандартное меню (Профиль, Баланс, Поиск, Сделки).

## 🚦 Текущий статус функционала
- **Регистрация / Анкеты**: ✅ Реализовано (`for_contacted`).
- **Модерация**: ✅ Реализовано (частично).
- **Главное меню клиента**: ✅ Реализовано (Каталог, баланс, история сделок, двухсторонние отзывы).
- **Редактирование профиля**: 🚧 Заглушки в `edit_profile_handler.py`.

## 🔄 Основные паттерны
- **Фасад Handler**: Все апдейты приходят в `message_handlers`, затем делегируются в специализированные функции.
- **Callback + Input Flow**: Паттерн "Нажал кнопку -> Бот спросил -> Ввел данные -> Сохранил".
- **Message Cleanup**: Активное использование `clear_messages` для удаления старых меню и диалогов, чтобы чат был чистым.
